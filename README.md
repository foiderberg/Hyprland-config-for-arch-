Please make sure you have ly installed for the login screen to fit the theme ( You don't have too) if you don't here is the code for arch linux
sudo pacman -S ly 
sudo systemctl enable ly.service 
For your current login screen to disable it do:
sudo systemctl disable (Your login manager eg: sddm or gddm or plasma login manager)
You don't have to disable your other ( if you have one ) desktop environment for hyprland to work just go to the bottom left or top left or top right or bottom right or basically where it says you current session.
